# NetTerm

Cliente de terminal para Windows: sesiones **SSH, Telnet, SFTP y FTP** en pestañas, con botones
personalizables que envían comandos o contraseñas guardadas con un clic.

## Descargar

👉 **[Descargar NetTerm.exe (última versión)](https://github.com/sneakydez/NetTerm-releases/releases/latest/download/NetTerm.exe)**

O entra en [Releases](https://github.com/sneakydez/NetTerm-releases/releases/latest) para ver las novedades.

## Instalar

1. Descarga `NetTerm.exe` y guárdalo donde quieras (por ejemplo en tu Escritorio o en `Documentos\NetTerm`).
   No necesita instalación.
2. Ábrelo con doble clic.
3. Si Windows muestra «Windows protegió su PC», pulsa **Más información → Ejecutar de todas formas**.
   Aparece porque el programa aún no está firmado digitalmente; no es un virus.

## Actualizaciones

NetTerm avisa cuando hay una versión nueva, muestra las novedades y solo se actualiza si pulsas
**«Actualizar ahora»**. Tus sesiones, botones y preferencias se conservan.

## Tus datos

Sesiones y contraseñas se guardan cifradas en tu equipo (`%USERPROFILE%\.netterm`), protegidas con tu
usuario de Windows. Nada se envía a ningún servidor.
